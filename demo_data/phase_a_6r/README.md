# Phase A 6R Reference Application

This directory contains only synthetic demo data. The Legacy Order Fulfillment
Suite is the application reference for `6R-01`; the existing Apex Oracle Customer
Analytics Warehouse remains the data-platform reference.

Run both through `engine.workflow.run_assessment` with their respective portfolio,
enterprise ID, and evidence registry. Phase A produces recommendations and stored
artifacts only. It grants no decision approval or execution authority.
