# Apex Aerospace Synthetic Enterprise

This package is the canonical deterministic sample for the standalone Mission Control prototype. Apex Aerospace Manufacturing is fictional, and every person, organization, cost, risk, dependency, and recommendation in the package is synthetic.

`sample-enterprise.js` contains the browser- and Node-compatible sample. It composes the existing deterministic portfolio scoring engine with the existing authoritative Enterprise DNA graph; it does not create a second workflow or Enterprise DNA state owner. `sample-enterprise.json` is a portable package descriptor for tutorials and tooling.

The package contains ten modernization units, five business units, eight business capabilities, APIs, data products, pipelines, dashboards, AI systems, infrastructure, technologies, accountable owners, risks, technical debt, readiness evidence, current and target states, a three-wave plan, and evidence for six modernization stages.

Run its focused validation from `prototype/mission-control/`:

```sh
node tests/synthetic-sample-portfolio.test.js
```
